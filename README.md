# NoteStudio

NoteStudio is a semester-wise study material platform for organizing and accessing notes, question banks, previous papers, and syllabi in one place.

## Features

- Browse notes by semester and subject
- Upload PDF, DOC, DOCX, PPT, and PPTX files
- View documents in the browser
- Download study materials
- Search by subject, code, or title
- Filter by material type and favorites
- Sort by newest or alphabetical order
- Mark important files as favorites
- Track recently viewed items
- Switch between light and dark modes
- Restrict editing and deleting to the owner/admin

## Getting Started

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open the local frontend in your browser using the URL shown by the dev server.

## Project Overview

This project is built as a full-stack web application using a Node.js backend and a frontend interface for managing academic study materials.
